# 🧪 Laboratory Safety Guide - Room 302

## 🚨 Emergency Protocols
- **Fire**: Exit through the North door and gather at Assembly Point B.
- **Spill**: Contain immediately using the spill kit located under the main sink.
- **Injury**: First aid kit is mounted next to the emergency shower.

## 🥽 Personal Protective Equipment (PPE)
1. **Lab Coats**: Must be worn at all times.
2. **Safety Goggles**: Mandatory when handling chemicals or pressurized systems.
3. **Gloves**: Use nitrile gloves for chemical handling; heat-resistant for furnace work.

## 🛠️ Equipment Calibration
Before starting any sensor-based experiments, ensure all devices are calibrated according to the **Manufacturer's Specification**. 

> **Note**: If you encounter an error code on the Smart Signage display, report it immediately via the **Maintenance QR Code**.

## 📅 Lab Hours
- **Monday - Friday**: 08:00 AM - 08:00 PM
- **Weekends**: Authorized personnel only.
