# Emergency Protocols

- **Fire**: Exit through the North door and gather at Assembly Point B.
- **Chemical Spill**: Contain immediately using the spill kit located under the main sink, then notify the lab supervisor.
- **Injury**: The first-aid kit is mounted next to the emergency shower; major incidents must be reported to Campus Security at extension 911.

# Personal Protective Equipment (PPE)

1. **Lab Coats** must be worn at all times inside the lab.
2. **Safety Goggles** are mandatory when handling chemicals or pressurized systems.
3. **Gloves**: nitrile for chemical handling, heat-resistant for furnace work.
4. **Closed-toe shoes**: no exceptions.

# Equipment Calibration

Before starting any sensor-based experiment, verify that every device on the workstation is calibrated against the manufacturer's specification. Re-calibration logs are stored at:

```
\\labshare\ECE302\calibration\<YYYY-MM>\
```

If a Smart Signage display reports an error code, scan the maintenance QR code on the side panel of the unit and submit a ticket via the IT Services portal.
